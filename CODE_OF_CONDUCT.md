# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Critique code, not people.

## Expected behavior

- Be welcoming to people at every level of experience. "This is a beginner question" is not a reason
  to be dismissive; it's a reason the docs might need work.
- Give and accept feedback about the work itself.
- Take responsibility for mistakes and fix them.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, sustained disruption, or publishing anyone's
private information.

## Enforcement

Report concerns to the maintainer through
[GitHub Security Advisories](https://github.com/jadghadry/react-virtual-checkbox-tree/security/advisories/new)
or by email via the GitHub profile. Reports are handled privately. Maintainers may remove comments,
close issues, or block accounts for behavior they judge inappropriate.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
